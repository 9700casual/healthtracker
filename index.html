Firebase Cloud Firestore

Realtidsdatabase direkte forbundet til din app

Ikke forbundet (Lokal tilstand)

Når Firebase er forbundet, gemmes alle registreringer fra + Log Data og hurtig-justeringer direkte i din egen sikre Google Firebase database i realtid. Du kan logge nede i træningscenteret fra din mobil, og det opdateres øjeblikkeligt her!

1

Opret projekt

Gå til console.firebase.google.com, log ind med din Google-konto og klik på "Opret et projekt" (gratis).

2

Aktivér Firestore

I menuen til venstre: Vælg Databases & Storage → Firestore → Create database → Vælg lokation → Vælg "Start in test mode".

3

Kopier din Web-config

Klik på tandhjulet ⚙️ Project Settings → scroll ned til "Your apps" → klik på Web-ikonet </> → kopier firebaseConfig blokken og indsæt den nedenfor!

Alternativ: Forbind Google Sheet (Valgfrit)

Automatisk Gemt i Skyen

Indsæt blot det normale link til dit Google Sheet fra adressebaren. Dashboardet gemmer automatisk forbindelsen i skyen, så du aldrig skal indtaste det igen!

1

Opret Sheet med 2 faner

Navngiv den første fane Sundhed og den anden fane Styrke.

2

Gør arket læsbart

Klik på den gule Del knap øverst til højre i Google Sheets, og ændr adgang til: "Alle med linket kan se".

3

Kopier & Indsæt Link

Kopier hele linket fra adressebaren i din browser (fx docs.google.com/spreadsheets/d/...) og indsæt det nedenfor!

Valgfrit: Skriv automatisk tilbage til Google Sheets

Når du bruger "+ Log Data" knappen i appen, gemmes dine tal automatisk i appens egen skylagring med det samme (du behøver slet ikke Google Sheets!). Hvis du også vil have, at appen automatisk skriver nye rækker ind i dit Google Sheet, kan du indsætte en Google Apps Script Web-App URL her:

  1. Åbn dit Google Sheet og klik på Udvidelser → Apps Script.
  2. Slet koden derinde og indsæt scriptet herunder:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet();
  var data = JSON.parse(e.postData.contents);
  if (data.type === 'health') {
    sheet.getSheetByName('Sundhed').appendRow([data.date, data.weight, data.fat, data.muscle, data.vo2]);
  } else if (data.type === 'strength') {
    sheet.getSheetByName('Styrke').appendRow([data.date, data.exercise, data.weight]);
  }
  return ContentService.createTextOutput("OK");
}

3. Klik på Implementer (Deploy) → Ny implementering → Vælg type: Web-app → Sæt "Hvem har adgang" til Alle (Anyone) → Kopier Web-app URL'en og indsæt her:
